## Detailed Directory Breakdown

### 1. [`langpeanut_local/CHANGELOG.md`](langpeanut_local/CHANGELOG.md)
* **Hackathon Evaluation Section**: Documents the formal multi-iteration progression (`Baseline → AST Scout → Patch Engine → Verifier Critic → Translation Memory → Final Orchestration`) with verified metric gains and cost reductions.
* **Adversarial Benchmark Analysis**: Detailed case-by-case breakdown comparing the naive regex baseline, raw zero-shot LLM baseline, and the deterministic `langPeanut` pipeline across 10 complex edge cases (nested JSX, Flutter ARB, iOS format specifiers, Android pluralization, ICU syntax).
* **Early Build Logs**: Full chronological interaction logs covering initial scaffolding, tree-sitter AST integration, byte-range surgical patch engine, and TUI implementation (Session Entries 1–97).

### 2. [`langpeanut_local/CHANGELOG1.md`](langpeanut_local/CHANGELOG1.md)
* **Cloud & Enterprise Integration**: Covers the evolution from the local CLI into `langpeanut-cloud` (Go REST/WebSocket server, Next.js dashboard, SQLite WAL storage, and Docker containerized runner execution).
* **Automated Autopilot & GitHub Integration**: Documents the implementation of GitHub App authentication, webhook push listeners, PR bot comment commands (`/localize`), deduplication engines, and the Translation Matrix & SEO Studio.
* **Sessions 98–111**: Direct chronological continuation of development decisions, root causes, actions taken, and verification steps.

### 3. [`langpeanut_local/CHANGELOG2.md`](langpeanut_local/CHANGELOG2.md)
* **Active Working Log**: Per the project development protocol in [`langpeanut_local/AGENTS.md`](langpeanut_local/AGENTS.md), all new user directives, bug fixes, architecture additions, and verification runs continue to be logged here chronologically starting from Session Entry 112 onwards.
